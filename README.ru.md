# Ярило

[English](README.md)

Яркость внешних мониторов из трея Windows: ползунок вместо кнопок на мониторе. Дополнительно —
автояркость по датчику освещённости, с дневной и ночной кривой, которые следуют за солнцем.

Ярило говорит с самим монитором по DDC/CI — каналу данных внутри видеокабеля. Меняется настоящая
яркость монитора, а не затемняется картинка.

## Что умеет

- **Ползунок.** Левый щелчок по солнцу в трее: один ползунок на все мониторы или по ползунку на
  каждый (снять галочку «Вместе»).
- **Ярче / Темнее** в меню и, если нужно, горячие клавиши (по умолчанию выключены).
- **Автояркость, если есть датчик.** Подойдёт любой адрес, который по HTTP отдаёт JSON с числом,
  например прошивка ESPHome из [`firmware/`](firmware/). К ней добавляются запись света и график.
- **Дневная и ночная кривая, если указан город.** При тех же 8 лк днём хочется ярче, чем вечером
  под лампой. Ярило смешивает две кривые по высоте солнца, плавно в сумерках.

## Что нужно

- Windows 10 или 11.
- Мониторы с DDC/CI. Он есть у большинства настольных мониторов; его можно выключить в меню
  самого монитора. Экраны ноутбуков работают не через DDC/CI, ими Ярило не управляет.
- 64-битный Python 3.10 или новее. `yarilo.cmd` найдёт его сам или скажет, что поставить.

## Установка и запуск

1. Скачать код: `git clone https://github.com/bsdate-cc/yarilo` или Code → Download ZIP.
2. Дважды щёлкнуть `yarilo.cmd`. При первом запуске он создаёт `.venv` и ставит библиотеки
   (pystray, Pillow, astral).
3. В трее появится солнце. Левый щелчок открывает ползунки, правый — меню. В меню же галочка
   «Запускать при входе в Windows».

## Работает ли мой монитор?

Запустить `probe.cmd` или `.venv\Scripts\python -m yarilo probe`. Для каждого монитора слева
направо он напечатает:
- отвечает ли монитор;
- его яркость и максимум;
- проходит ли запись той же яркости обратно;
- какие коды VCP монитор сам о себе перечисляет.

Если монитор не отвечает:
- включите DDC/CI в его меню;
- подключите кабель напрямую. Док-станции, KVM-переключатели и часть переходников USB-C/HDMI
  DDC/CI не пропускают.

Если что-то совсем странное, дайте своему агенту [`docs/for-agents.md`](docs/for-agents.md) и вывод
`probe --json`.

## Настройки

Файл настроек — `%USERPROFILE%\.yarilo\config.json`. Открыть его можно из меню → «Открыть
настройки»; правки Ярило подхватывает на ходу. Мониторы нумеруются слева направо с 1. Чего нет в
файле, берётся по умолчанию из [`yarilo/config.py`](yarilo/config.py).

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `language` | `"auto"` | `"ru"` или `"en"`; auto — как в Windows |
| `linked` | `true` | один ползунок на все мониторы |
| `monitor_offsets` | `[]` | добавка к общей яркости слева направо, например `[5, 0]`, если левый на вид темнее |
| `skip_monitors` | `[]` | номера мониторов, которые Ярило не трогает, например `[3]` |
| `vcp_code` | `16` | 0x10 — яркость по стандарту DDC/CI |
| `step` | `5` | шаг для Ярче/Темнее и горячих клавиш |
| `min`, `max` | `0`, `100` | пределы в процентах |
| `hotkeys` | `{"brighter": "", "darker": ""}` | например `"ctrl+alt+up"`, `"ctrl+alt+down"` |
| `sensor_urls` | `[]` | адреса датчика; если указан хоть один, включается автояркость |
| `sensor_json_field` | `"value"` | поле JSON с числом люксов |
| `location` | `null` | `{"name": "Москва", "lat": 55.75, "lon": 37.62}` включает ночную кривую |
| `points_day`, `points_night` | см. config.py | точки `[люксы, яркость]` |
| `smooth` | `true` | автояркость меняется по единице; `false` — одной записью |

## Автояркость

Как она решает:
- **Не реагирует на короткие изменения.** Берёт медиану света за 20 секунд, поэтому рука или тень
  ничего не меняют.
- **Меняет редко.** Только если нужная яркость отличается от текущей на 4 и больше в течение
  30 секунд. При скачке на 15 и больше, например когда включили свет в комнате, хватает 5 секунд.
- **Не спорит с ручной настройкой.** Ползунок или Ярче/Темнее выключают автояркость; вернуть её можно галочкой
  «Автояркость». Если яркость поменяли кнопками на самом мониторе, Ярило не трогает её час.

Монитор может сохранять каждую смену в своей памяти. Поэтому Ярило меняет яркость редко, и для этого
же есть настройка `smooth`.

Датчик в [`firmware/`](firmware/) — ESP32-C3 Super Mini с GY-302 (BH1750) на ESPHome; пайка и
прошивка описаны там. Корпус для печати, который вешается на стену, — в
[`hardware/case/`](hardware/case/). Запись света лежит в `%USERPROFILE%\.yarilo\lux\`. Меню → «График света»
открывает страницу со всеми днями, восходом и закатом.

## Файлы

Всё в `%USERPROFILE%\.yarilo\`:
- `config.json` — настройки;
- `yarilo.log` — журнал;
- `lux\` — запись света, если есть датчик;
- `lux.html` — график.
